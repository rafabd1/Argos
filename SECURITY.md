# Security Policy

## Reporting A Vulnerability

Please report security issues through GitHub private vulnerability reporting for
the Argos repository. Include the affected version, reachable entry point,
impact, and the smallest reproduction that shows the issue.

Do not open a public issue for an unpatched vulnerability in Argos.

## Research Use

Argos is intended for authorized security research. Users remain responsible
for target permission, scope, data handling, and applicable law.
